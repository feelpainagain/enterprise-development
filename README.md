Лабораторная работа 1, Пункт велопроката
Описание проекта
Проект иметирует основные сущности пункта велопроката, генерации тестовых данных и тесты для проверки

Реализовано:
BikeRental.Models – модель пункта велопроката.
BikeModel – модель велосипеда: тип (горный, дорожный, гибридный), размер колёс, допустимый вес пассажира, масса велосипеда, тип тормозов, год выпуска и почасовая цена аренды.
Bicycle – конкретный велосипед: ссылка на модель, серийный номер и цвет.
Renter – клиент проката: ФИО и номер телефона.
RentalContract – договор аренды: клиент, велосипед, дата и время начала аренды и длительность в часах.

Тесты проверяют:
Нахождение всех спортивных велосипедов (горные и дорожные модели).
Топ‑5 моделей по общей длительности аренды.
Топ‑5 моделей по суммарной прибыли от аренды.
Общую длительность аренды по типам велосипедов.
Статистику по длительности аренды (минимум, максимум, среднее значение).
Топ‑5 клиентов по количеству аренд.
