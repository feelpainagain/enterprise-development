# BikeRental Лабораторная работа 2–3

**Стек**
- .NET 8
- Entity Framework Core + реляционная БД
- xUnit
- .NET Aspire

### Модель данных

Доменные сущности:  
- **BikeModel** – модель велосипеда (Type, WheelSize, MaxPassengerWeight, BikeWeight, BrakeType, ModelYear, HourlyRentalPrice).  
- **Bicycle** – конкретный велосипед (ModelId, SerialNumber, Color).  
- **Renter** – клиент проката (FullName, PhoneNumber).  
- **RentalContract** – договор аренды (BicycleId, RenterId, StartTime, RentalDurationHours).  

### Unit‑тесты

Реализованы unit‑тесты на xUnit для всех аналитических запросов, указанных в задании.

## Реализованные штуки

**Infrastructure** – `BikeRentalPointDbContext` для работы с базой данных, EF‑репозитории для всех сущностей, миграции и начальное заполнение данными.  
**Api** – Web API‑контроллеры для CRUD‑операций с моделями, велосипедами, арендаторами и договорами, а также отдельный контроллер для аналитики.  
**AppHost** – конфигурация запуска сервера и базы данных с помощью .NET Aspire.  
**Contracts** – DTO‑модели для операций создания, обновления и чтения сущностей через API.

## Тесты проверяют

1. Получение всех «спортивных» велосипедов (горные и шоссейные модели).  
2. Топ‑5 моделей по суммарной длительности аренды.  
3. Топ‑5 моделей по суммарной прибыли от аренды.  
4. Суммарное время аренды, сгруппированное по типу велосипеда.  
5. Минимальную, максимальную и среднюю длительность аренды.  
6. Топ‑5 клиентов по количеству аренд.
