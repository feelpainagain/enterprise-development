# BikeRentalPoint Лабораторная работа 4

**Стек**
- ASP.NET Core + gRPC
- Bogus
- EF Core + MySQL
- .NET Aspire
- xUnit

**Генерация данных** – Генерация моделей, велосипедов, арендаторов и аренд с помощью Bogus через gRPC‑сервис `GenerationService`.  
**gRPC‑консюмер** – `GrpcClientConsumer` в Web API, который вызывает gRPC‑сервис, принимает батчи данных и сохраняет их в БД через EF Core‑репозитории.  
**Web API** – Контроллеры для управления моделями, велосипедами, арендаторами, арендами и получения аналитики (top‑модели, клиенты и т.п.).  
**Aspire AppHost** – Оркестрация MySQL и сервисов, health‑checks, общие настройки телеметрии и HTTP‑клиентов.
